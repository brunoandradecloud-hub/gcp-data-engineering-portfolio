# 🎯 Metodologia de Geração de Simulados — Data Engineer

## 📋 Regras de Conteúdo (Módulo 01)
As questões devem obrigatoriamente cobrir:
- **Arquitetura de Data Lake:** Camadas Raw, Processed e Curated.
- **Ingestão:** Batch vs Streaming (Datastream + Dataflow).
- **BigQuery:** Tabelas Nativa, External Tables e BigLake (Iceberg).
- **Bancos de Dados:** AlloyDB, Cloud Spanner e Bigtable.
- **Machine Learning:** BigQuery ML (BQML), Embeddings, Vector Search e Vertex AI.
- **Segurança/Governança:** Dataplex, DLP e Cloud KMS (CMEK).

## 📊 Níveis de Raciocínio (Mix de Prova)
- **30% Conceituais:** Teste de definição de termos.
- **40% Decisão Arquitetural:** "Qual a melhor estratégia para o cenário X?".
- **30% Armadilhas de Prova:** Detalhes sutis (ex: BQML não aprende incrementalmente).

## ✍️ Padrão de Estrutura (Estilo Google Cloud)
1. **Cenário:** Contexto de negócio (ex: "Uma casa de câmbio digital...").
2. **Necessidade:** O problema técnico ou restrição de custo/performance.
3. **Pergunta:** "Qual a solução recomendada?".
4. **Opções:** 4 alternativas (A, B, C, D) curtas e objetivas.

## 🔑 Regras para o Gabarito
- Indicar a letra correta.
- **Justificativa:** Explicar o conceito técnico por trás da resposta e desmitificar as erradas.
