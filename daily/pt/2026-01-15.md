# O que aprendemos hoje — BigQuery ML, Embeddings e Vector Search

## 1️⃣ BigQuery ML: ciclo completo do modelo

### Criar o modelo (`CREATE MODEL`)

- O modelo é treinado a partir de uma tabela ou view  
- Os targets (labels) vêm de colunas existentes  
- Normalmente dados da camada Curated  
- Usado para:
  - classificação
  - regressão
  - clustering
  - embeddings

**Pontos importantes**
- O modelo não aprende incrementalmente  
- Para atualizar, é preciso recriar o modelo  
- Um novo treinamento não herda conhecimento do anterior  

---

## 2️⃣ `ML.EVALUATE`: avaliar qualidade do modelo

- Não faz predição  
- Mede a qualidade do modelo  
- Usado após o treinamento  

**Métricas comuns**
- accuracy
- precision
- recall
- F1-score
- AUC (dependendo do tipo de modelo)

**Quando usar**
- validação antes de disponibilizar o modelo  
- comparação entre versões  
- análise por analistas ou engenheiros  

---

## 3️⃣ `ML.PREDICT`: usar o modelo para análise

- Aplica o modelo em novos dados  
- Funciona como uma query SQL  
- Não altera o modelo  
- Pode ser usado diretamente por analistas  

**Casos típicos**
- prever churn  
- classificar transações  
- auxiliar análises exploratórias  
- enriquecer datasets analíticos  

---

## 4️⃣ Targets (labels): que tipo de dados usar

- Normalmente vêm de:
  - dados transacionais históricos  
  - eventos consolidados  
  - dados previamente rotulados  

**Exemplos**
- churn (sim / não)  
- tipo de transação  
- status de operação  
- categoria de atendimento  

> Targets não são dados criados só para ML, são dados reais do negócio.

---

## 5️⃣ O que é embedding

- Representação numérica de dados não estruturados  
- Muito usado para:
  - texto
  - linguagem natural
  - similaridade semântica  

**Importante**
- Não substitui códigos transacionais  
- Não faz sentido para enums simples  
- Faz sentido para texto livre  

---

## 6️⃣ Quando embedding faz sentido (e quando não)

❌ Não faz sentido:
- códigos numéricos  
- status fixos  
- enums bem definidos  

✅ Faz sentido:
- mensagens de chat  
- descrições  
- comentários  
- reclamações  
- textos livres  

**Exemplo**
- “Transferência recusada por limite diário” → embedding  
- `cd_status = 2` → não embedding  

---

## 7️⃣ Vector Search no BigQuery

- Embeddings permitem vector search  
- Vector search permite:
  - busca semântica  
  - agrupamento por significado  
  - identificação de padrões em texto  

**Exemplo prático**
- entender principais temas em chats  
- agrupar reclamações semelhantes  
- encontrar mensagens semanticamente próximas  

---

## 8️⃣ Encaixe arquitetural validado

- Dados de chat → camada Curated  
- Embeddings → BigQuery ML  
- Busca semântica → VECTOR_SEARCH  
- Avaliação → ML.EVALUATE  
- Uso analítico → ML.PREDICT  

---

## Resumo final

Hoje aprendemos como transformar dados consolidados e textos livres em modelos analíticos úteis no BigQuery, avaliá-los corretamente e usá-los de forma prática, incluindo embeddings e busca semântica.
