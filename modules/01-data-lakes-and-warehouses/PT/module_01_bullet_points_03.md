
# 📌 Módulo 01 — Bullet Points (Governança e Machine Learning)

## 🏛️ Governança de Dados — Dataplex
- Camada de governança do Data Lake e Data Warehouse
- Não executa processamento nem consultas
- Atua sobre Cloud Storage, BigQuery e BigLake
- Centraliza metadados técnicos e de negócio
- Facilita auditoria, compliance e organização por zonas
- Não é pré-requisito para BigQuery ML ou Vertex AI

## 🔐 Data Loss Prevention (DLP)
- Identifica e classifica dados sensíveis
- Atua sobre Cloud Storage e BigQuery
- Não criptografa nem altera dados
- Gera metadados de classificação
- Suporta políticas de acesso e auditoria

## 🔑 Cloud Key Management Service (KMS)
- Gerencia chaves de criptografia
- Protege dados em repouso
- Integrado com Cloud Storage, BigQuery e BigLake
- Suporta rotação, controle de acesso e auditoria

## 🤖 BigQuery ML (BQML)
- Usado com dados consolidados e estáveis
- Criação e uso via SQL
- Requer recriação para atualização do modelo
- Não reaproveita aprendizado anterior

## 🤖 Vertex AI
- Usado para ML avançado e produção
- Suporta pipelines, MLOps e retreinamento contínuo
- Integra com BigQuery e Cloud Storage

## 🧠 Resumo Mental
- Dataplex governa
- DLP identifica
- KMS criptografa
- BQML simplifica
- Vertex AI escala
