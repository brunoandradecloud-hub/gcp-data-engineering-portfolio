
# Module 01 — Bullet Points 02

- Modern architecture separates analytical and operational workloads
- Data Lake on Cloud Storage reduces cost and increases flexibility
- Raw layer: raw data, append-only, External Tables
- Processed layer: transformations, Parquet, Iceberg when ACID and history are required
- Curated layer: final consumption, native BigQuery tables and BigLake
- BigLake enables the Lakehouse pattern without data duplication
- Iceberg provides ACID, Time Travel, and metadata control
- External Tables are ideal when there is no concurrency or mutability
- BigQuery is fully managed and serverless
- AlloyDB supports modern regional applications
- Cloud Spanner is required for global scale and strong consistency
